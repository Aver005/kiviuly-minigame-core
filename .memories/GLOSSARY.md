# GLOSSARY
> Project-coined terms & acronyms. One line each. Last updated: 2026-07-24

| Термин | Значение |
|---|---|
| **Платформа / ядро** | `kiviuly-mg-core` = модули `mg-api` + `mg-core`; плагин называется `MgCore` |
| **`mg-api`** | jar с контрактами **и общим тулкитом**; игры компилируются против него |
| **`mg-core`** | Paper-плагин с движком; ставится на игровой сервер |
| **Игра / мини-игра** | отдельный плагин, реализующий `Minigame` (SkyWars, SkyBlockWars, Escape) |
| **Матч (`Match`)** | один запущенный поединок на арене; реализация — `GameSession` ядра |
| **Арена (`Arena`)** | статический конфиг площадки: мир, лобби, спавны, лимиты, тайминги |
| **«Карман чисел»** | `Arena.getSetting/setSetting` — игро-специфичные числа без правки контракта |
| **«Карман точек» / spots** | `Arena.spots(group)` — именованные группы координат с ярлыками |
| **Ярлык (tag)** | строка на точке: id категории лута, тип торговца, имя рычага, сторона |
| **Slug игры** | короткий id игры в команде (`skywars`), нужен `/mg` при конфликте id арен |
| **Владелец арены** | `Arena.getGameId()` — какой игре принадлежит арена |
| **Хук** | метод `Minigame`, который зовёт ядро (`onStart`, `onTick`, `checkResult`…) |
| **Правила (`EscapeRules`)** | у Escape — бывший `GameSession` без движка: логика игры + хуки |
| **`EscapePlayerData`** | у Escape — бывший `MatchPlayer`, 13 полей; переименован из-за конфликта имён |
| **Фасад `EscapeArena`** | типизированный доступ Escape к «карманам» платформенной арены |
| **Каст** | так в Escape называется кит/стартовый набор (`Kit`) |
| **Респавн-блок** | персональный якорь возрождения игрока в Escape |
| **Финальная битва** | фаза Escape после истечения таймера: якоря аннулированы, играем без времени |
| **Разминка** | лобби-PvP до старта: SkyWars копит урон, SkyBlockWars — дуэли |
| **Хаб** | будущий отдельный сервер с выбором игры (`mg-hub`, ещё не написан) |
