# CONVENTIONS
> Style rules + invariants to follow when editing. Last updated: 2026-07-24

## Стиль (единый во всех четырёх репозиториях)

- Java 25, Paper API 26.1.2, Gradle Kotlin DSL, **ноль внешних зависимостей** в играх
  (драйвер SQLite берётся из Paper). Не добавляй библиотеки без веской причины.
- **Allman-скобки**: `{` на новой строке. Короткие тела в одну строку:
  `public int aliveCount() {return match.aliveCount();}`.
- Отступ 4 пробела, кодировка UTF-8, комментарии и javadoc — **по-русски**
  (так во всём проекте), ASCII — только в логах и `DebugLog`.
- Комментарий объясняет **почему**, а не что. Пример из кода: «второй проход С физикой:
  соседи пересчитывают стыки (иначе остаются щели)».

## Инварианты платформы (нарушение = баг)

1. **Откат мира.** Меняешь блок в матче — сначала `match.rememberBlock(block)`
   (или `rememberState` для `BlockPlaceEvent`). Спавнишь сущность — `match.trackEntity`.
2. **Целость игрока.** Ядро снимает снапшот на входе и восстанавливает на любом выходе.
   Игра не должна сама менять инвентарь вне матча.
3. **Ни одной строки игроку в Java.** Только ключи `messages.yml` через `Msg`.
   Новый текст = новый ключ. Ключи игры — в её неймспейсе (`skywars.*`, `sbw.*`).
4. **Данные предметов/сущностей — только PDC** (`Keys` / свои `<Игра>Keys`).
   Никогда не парсить display-name и лор.
5. **Main thread.** Вся игровая логика синхронная; async — только хранилище статистики.
6. **Состояние матча — в матче**, не в полях `Minigame`. Инстанция игры одна, матчей много.

## Правила для игрового плагина

- `plugin.yml`: `depend: [MgCore]`, своя команда, своё право (`<slug>.admin`).
- В `onEnable`: взять `MgCore` из `ServicesManager`, `Msg.merge(this)` (**не `init`**),
  `core.register(game)`, команду через `core.commandFor(game)`.
- **Не регистрировать свой `MenuListener`** — иначе двойная обработка кликов.
- Числа арены — через `arena.getSetting(...)`, точки — через `arena.spots(group)`;
  контент (списки) — в своём `game/<ID>.yml`, не в арене.
- После правки арены — `core.arenas().save(arena)`.

## Проверка перед «готово»

```bash
cd <repo> && ./gradlew build
```
Компиляция — необходимый минимум, но **не достаточный**: рантайм в этом проекте пока
не проверялся ни разу (см. `STATE.md`). Не пиши «работает», если только собралось.

## Дисциплина памяти

Любое непустяковое изменение = обновить `STATE.md` (+ `BUGS.md`/`PLANS.md` при
необходимости) и добавить запись в `JOURNAL/<дата>.md`. Память, которой не доверяют,
хуже отсутствующей.
