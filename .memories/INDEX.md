# .memories INDEX
> Agent entry point. If you were handed this project cold, START HERE. Last updated: 2026-07-24

The **app does not auto-load this folder** — an agent only benefits if it is told
to read `.memories/INDEX.md` first (that is what the root bridge file is for).

## Порядок чтения

| # | Файл | Зачем | Когда |
|---|---|---|---|
| 1 | `QUICKSTART.md` | что это, 4 репозитория, как собрать, горячие файлы | всегда |
| 2 | `STATE.md` | что готово, что сломано, текущий фронт | **всегда** |
| 3 | `PLANS.md` | следующий шаг и открытые решения владельца | перед работой |
| 4 | `CONVENTIONS.md` | инварианты, которые нельзя нарушать | перед правкой кода |
| 5 | `LEARNINGS.md` | грабли, на которые уже наступали | перед правкой кода |
| 6 | `ARCHITECTURE.md` | слои, модель, почему так решено | при архитектурных вопросах |
| 7 | `MAP.md` | где что лежит во всех четырёх репозиториях | при поиске кода |
| 8 | `GLOSSARY.md` | термины проекта (каст, spots, slug, правила) | если непонятен жаргон |
| 9 | `BUGS.md` | известные дефекты и подозрения | при отладке |
| — | `JOURNAL/` | что делали и почему, по датам | для контекста решений |

## Легенда статусов

`[DONE]` готово · `[WIP]` в работе · `[TODO]` запланировано · `[BUG]` дефект ·
`[IDEA]` идея · `[?]` не проверено / под подозрением · `→ path:line` ссылка в код.

## Ключевой контекст в одном абзаце

Это **платформа мини-игр** плюс три игры в соседних репозиториях. Две игры уже
переехали на платформу, третья (**Escape**) — в процессе, и её репозиторий **сейчас
не собирается намеренно**. Владелец сознательно отказался от промежуточных зелёных
сборок: «тест в конце, всё вместе». Не пытайся «починить» Escape откатом — читай
`PLANS.md`, там расписан оставшийся шаг.

## Внешний контекст

- `docs/` в этом репозитории — человекочитаемая документация платформы. Она **частично
  устарела**: писалась до появления реестра игр, per-game папок арен, привязанных
  команд и прав. Приоритет у `.memories/`, обновление `docs/` стоит в `PLANS.md`.
- У `escape-reborn` есть **свой** `.memories/` — про саму игру Escape (её механики,
  геймдизайн). Он про игру, этот — про платформу и миграцию.

## Правило поддержки

Обновление памяти — часть «готово», а не отдельная задача. Любое непустяковое
изменение: обнови `STATE.md`, при необходимости `BUGS.md`/`PLANS.md`, добавь запись в
`JOURNAL/<дата>.md` и поправь `Last updated`.
