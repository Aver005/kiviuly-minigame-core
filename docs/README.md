# kiviuly-mg-core — документация

Общий фреймворк-платформа для мини-игр Kiviuly. Вытаскивает повторяющиеся понятия
(Арена, Матч, Игрок-в-матче, лобби, статистика, HUD, откат мира) из отдельных
мини-игр в один переиспользуемый core, поверх которого каждая игра пишет только
свои правила.

Package root: `ru.kiviuly.mg`. Java 25, Paper 26.1.2, Gradle (Kotlin DSL).

## Термины (кратко)

- **Арена** — статический конфиг одной площадки (мир, лобби, спавны, лимиты, тайминги).
- **Матч** (`Match`, реализация — `GameSession`) — один запущенный поединок на арене.
- **Игрок-в-матче** (`MatchPlayer`) — состояние конкретного игрока в конкретном матче.
- **Minigame** — правила одной игры; шов расширения, который реализует каждая мини-игра.
- **Core / платформа** — `mg-core`: ведёт матч, не зная правил.
- **Хаб** — отдельный сервер-лобби с выбором игры.

Полный глоссарий — внутри [01-architecture.md](01-architecture.md).
